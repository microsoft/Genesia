# Dayline Spec＋截图研究样例

[English](README.md) | [运行用例](../README.md) | [研究报告](report.md)

这是一场使用当前流程完成的 **20 Persona 完整研究**的经审阅公开版本。
环境构建、材料体验、访谈和分析在同一次运行中完成，没有使用分析恢复补跑，
也没有拼接其他研究的参与者或答案。本次使用 `gpt-6.1-sol`、温度1，以及V3答题规则。

## 实际运行结果

| 项目 | 结果 |
|---|---|
| 输入 | 一份 Spec、11 张 Design A 静态截图 |
| 环境构建 | 11 个状态、11 张带图 Card、26 条有文本依据的转换 |
| 共享背景 | 保留 13 段逐字引用的背景与限制 |
| Cohort | 从公开合成池中固定选择的 20 个授权 Persona |
| 研究 | 每人 10 题，分两批，无追问 |
| 执行 | 110 步，20 份有效访谈；0 无效或缺失访谈，0 失败动作 |
| 分析 | 200/200 个有效答案已处理，6 项发现，4 项建议 |
| 证据校验 | 882 个证据条目的完整性校验通过 |

Persona 自主选择查看已捕获的状态，不是操作实时应用。已核对每次访谈请求，
实际看过的文字和截图都被传入。本次选定的完整run没有模型输出校验修正或人工改答案。
此前失败尝试单独保留，没有把其参与者或答案合并进本次研究。

保真审查记录了两处编译状态文字遗漏：Message Workstream显示的action intent到期时间，
以及Message Result中的Medium风险和不可撤回警告。原始截图仍保留在来源证据中。
这限制了文字表示的完整性，不能声称已测试到期或撤回行为；引用和哈希校验也不证明语义完整。

## 研究结果

[报告](report.md)保留原始中文综合、发现、建议和限制。主要结论是：
应保留并列上下文和独立决策边界，改善辅助文字可读性及授权术语；
具体内容、访问范围和责任归属仍需按场景验证。

| 感知有用性 | 数量 |
|---|---:|
| Useful | 17 / 20 |
| Mixed | 3 / 20 |
| Not useful | 0 / 20 |
| Insufficient material | 0 / 20 |

这是本组合成 Persona 的描述性选择，不是采用率，也不能用于证明材料模式比实时
原型研究更好或更差。新运行不保证复现相同路径、答案或比例。从整个公开池按 seed
抽样，也不等于选择本样例的固定历史 cohort。

## 公开边界

公开报告删除本地运行标题、私有附录链接和执行元数据，增加合并证据人数的阅读说明。
其余研究正文保持不变，不是第二次模型分析，也不是独立重复研究。

[来源清单](manifest.json)保留原始状态、哈希、本样例的模型／服务配置和公开处理方式。

所以模型 ID 不代表固定版本保证。

样例不含完整画像、原始 Persona／session ID、原始答案、模型请求或运行目录，
这些保留在私有研究记录中。静态材料不能验证验收、授权、投递、持久化、真实 Agent、
移动端或辅助技术可用性。所有反馈均为合成研究，不代表真实用户或总体分布。
