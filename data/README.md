# Public Synthetic Persona Data

## Global Digital 100

[Global Digital 100](personas/global-digital-100/README.md) contains 100 explicitly
fictional adult Personas for qualitative digital-product research. Its
[personas.json](personas/global-digital-100/personas.json), quality summary and
publication manifest are preserved together.

Every record is marked `synthetic_status: fictional_public_example`. The data
provides perspective coverage, not human-participant evidence, population
representation, consent from real people or a guarantee of research suitability.
The pool's documented quotas apply to all 100 profiles, not arbitrary subsets.

Document-based examples sample three profiles with a fixed seed. To use a
different authorized source, change `cohort.source`; paths inside a task resolve
relative to that task. Review data, sending permissions, endpoint and retention
before running a study.
