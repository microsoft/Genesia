# Dayline A／B 比较研究样例

[English](README.md) | [自己运行](../README.md) | [操作 GIF](index.html)

这份公开样例展示 **20 个合成 Persona 对比 Dayline 两种布局**的过程与结果，
包含基于原340步记录新生成的400个访谈回答。当前访谈与报告使用 `gpt-6.1-sol`、
温度1及V3答题规则，没有拼接不同研究的人物或答案。

## 阅读结果

- [原生报告](report.md)／[HTML](report.html)。
- [单文件报告](standalone-report.html)，内嵌一条完整旅程。
- [全部20条旅程](index.html)／[P01预览](journeys/p01-paired.gif)。
- [偏好选项与理由](preferences.json)。

原生报告是Genesia基于本次新回答生成的中文综合结果。
HTML和单文件版本展示同一份研究结论，不是额外分析。

## 样例展示了什么

| 偏好 | 人数 |
|---|---:|
| Design A | 14 / 20 |
| Design B | 4 / 20 |
| 无明显偏好 | 2 / 20 |
| 经验不足 | 0 / 20 |

核心取舍是细读空间与状态总览。报告讨论如何保留两者的价值、改善阅读空间和拒绝后的
反馈路径，并让支持判断的信息更容易检查。这些偏好不证明因果优势、真实采用或执行质量。

## 研究来源与范围

| 项目 | 范围 |
|---|---|
| Cohort | 20位固定授权合成 Persona，以 P01–P20 展示 |
| 体验 | 固定 A→B，浏览器状态隔离，自主探索 |
| 访谈 | 20题，按8+8+4分批，无追问 |
| 数据 | 20份有效响应、400个回答、340步；0无效、0缺失、0失败动作 |
| 分析 | 覆盖全部400个有效回答；10项发现、6项建议 |

新访谈与原生分析均为**completed**。原体验来源仍为**partial**，其20份保存旅程原样复用；
本次为全部20人重新生成最终回答，但没有重跑浏览器交互或初始intent。
来源清单分别保留两个状态，不改写原研究。

[发布清单](manifest.json)保留研究日期、来源关系、文件哈希和逐帧引用。完整原始资料、
内部模型部署配置和操作审计记录不在公开范围内。公开展示版保留发现、建议、计数和
研究限制，移除了内部环境、发行与排障叙述。

**版本对应：公开 A＝源 Design B，公开 B＝源 Design D。** 文案、引语和 GIF 头部的版本名
作了明确替换。新的回答与偏好来自本次新访谈，截图内容、动作顺序和GIF字节不变。
[原型来源](prototype.json)记录研究快照；可运行源码已包含在[用例中](../README.md#run-the-bundled-case)。

## 媒体和发布边界

每个 GIF 保留该 Persona 的完整 A→B 旅程。画面是标注动作**之前**保存的观察；
黄色圆圈是记录的点击目标，不是鼠标轨迹。每步2秒、末帧4秒是演示速度，不代表实际耗时。
ADVANCE 和 STOP 是研究控制，不是产品按钮。

不公开完整画像、源 Persona／session ID、模型请求、完整原始轨迹、私有附录、凭据和
本机路径。截图中仍包含合成产品数据和 Persona 输入的虚构任务文本。你自己生成的
run 目录包含更多信息，不能未经审阅直接发布。

这些是合成会话，不是真人研究或总体代表样本。固定顺序、携带效应及自主且不匹配的路径
限制了比较。未验证真实 Agent 动作、发送／发布、跨设备持久化或辅助技术体验；
哈希只验证文件完整，不认证每个解释都正确。

GitHub 不直接运行 HTML，请下载样例后本地打开报告和图集。新运行使用你的模型及
选定 cohort，复用研究流程不等于复现相同答案或偏好比例。
