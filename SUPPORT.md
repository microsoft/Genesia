# Support

## How to File Issues and Get Help

This project uses this repository's **Issues** tab to track bugs
and feature requests. Search existing issues before filing a new one to avoid duplicates. Include the
affected version, operating system, expected and actual behavior, and reproduction steps. Do not
include credentials, private Persona data, screenshots, recordings or generated research reports.

For usage questions, first review the [README](README.md), the [`docs/`](docs/) directory and existing
issues. If the available documentation does not answer the question, open a GitHub issue with a
minimal, non-sensitive example.

Security vulnerabilities must not be reported through public issues. Follow
[SECURITY.md](SECURITY.md) instead.

## Microsoft Support Policy

Support for Genesia is limited to the community resources listed above. This project is provided
as-is and is not covered by a Microsoft Customer Service and Support (CSS) support contract.
